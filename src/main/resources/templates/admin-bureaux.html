Bureaux de conservation

Les bureaux reçoivent les demandes et regroupent les conservateurs qui les traitent. Chaque bureau tient un ou plusieurs livres fonciers : le code du livre, à la fin du numéro d'un titre foncier, permet d'affecter automatiquement une demande portant sur un bien.
